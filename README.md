# MindCare AI 🌿

MindCare AI is an AI-powered mental wellness support chatbot developed using Flask and the Google Gemini API.

## Features
- User registration and login
- Adaptive AI-powered conversations
- Friendly chatbot interface with emojis
- Conversation history
- Wellness reports and general guidance

## Technologies Used
- Python
- Flask
- Google Gemini API
- SQLite
- HTML, CSS, JavaScript

## How to Run
1. Install Python.
2. Install the required dependencies from `requirements.txt`.
3. Create a `.env` file containing your own Gemini API key and Flask secret key.
4. Run the application using `py app.py`.

## Important
MindCare AI provides general wellness support and is not a substitute for professional mental health care.

Never upload API keys, passwords, or private user data.
